# Qwen-AgentWorld prompt templates

The files `mcp_system_prompt.txt`, `terminal_system_prompt.txt`, and
`swe_system_prompt.txt` are unmodified copies of the corresponding
`prompts/<domain>/system_prompt.txt` files from
[QwenLM/Qwen-AgentWorld](https://github.com/QwenLM/Qwen-AgentWorld).

They are distributed under the Apache License 2.0; see [LICENSE](LICENSE).
The EJEPA integration adapter appends benchmark-specific output instructions at runtime
without modifying these source template files.
